☁ GitHub 云同步

填一次，多设备自动实时同步（掌握/错因/笔记/待办）。token 只存在你这台设备的浏览器里。
1：GitHub 建 public 仓库（如 pmp-sync），空仓库即可。
2：Settings → Developer settings → Personal access tokens → Fine-grained → Generate，只勾该仓库，Contents=Read and write。
3：填好下面，点测试并保存。
